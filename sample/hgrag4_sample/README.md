# HGRAG benchmark sample

This directory is a redistributable sample of the artifacts behind the
paper *Association by Design: A Brain-Inspired Hybrid Retrieval Architecture
for Multi-Hop Retrieval-Augmented Generation* (HGRAG).

It lets a reader do three things without standing up Elasticsearch or
calling an LLM API:

  1. run the retriever (dense + entity-graph + lexical routes);
  2. recompute every significance test in the paper from the released
     per-question result vectors;
  3. start the LLM-agnostic API proxy and watch the context injection.

## Contents

| Path | What it is |
|---|---|
| `kg/passages.json` | passage corpus (`title`, `text`) |
| `kg/questions.json` | benchmark questions with their original human annotations |
| `kg/splits.json` | the seeded 44/67 dev/test partition (seed 20240917) |
| `kg/entities.json` | extracted entities |
| `kg/relations.json` | extracted relation triples |
| `kg/activation_network.json` | materialized activation network with edge weights |
| `kg/raw_extractions.jsonl` | raw LLM extraction records (so the graph can be rebuilt without any API call) |
| `results/*.json` | per-question result vectors and summary statistics for every experiment |
| `MANIFEST.json` | file list with SHA-256 digests |

The `kg/` directory has exactly the layout that `hgrag4_run.py --kg-dir` expects,
so no path rewriting is needed on the reader's side.

## Provenance

The corpus and questions are the HotpotQA *distractor* split, taken from
its official public release. Human annotations (`gold_titles`, `answer`,
`supporting_facts`, `type`, `level`) are used verbatim; no question was
generated by an LLM and no synthetic distractor was introduced. The
entity/relation extraction was produced by a hosted LLM endpoint; the raw
records are included so that the graph can be reconstructed without any
further API call. The graph is therefore *not* byte-reproducible across
different extraction models, but every retrieval number in the paper is
computed against the frozen graph shipped here.

## Reproducing

```bash
pip install torch sentence-transformers numpy networkx scipy

# retrieve
python hgrag4_run.py --kg-dir sample/kg --out-dir ./out --stages 1

# re-check every numeric claim in the manuscript against the results
python hgrag4_verify_paper.py --results sample/results/summary.json --tex "access (4).tex"

# verify that the sample runs and that its significance numbers recompute
python hgrag4_verify_sample.py --sample sample

# verify the API proxy's "no backend modification" claim
python hgrag4_verify_proxy.py --kg-dir sample/kg

# run the proxy (add --backend-url http://127.0.0.1:8001/v1 for a real LLM)
python hgrag4_proxy.py --kg-dir sample/kg --port 8000 --dry-run
```
